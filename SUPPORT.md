# Support

Use GitHub issues for bugs, feature requests, and documentation problems:

https://github.com/zackyalgiffari/ghost-env/issues

For security vulnerabilities, follow `SECURITY.md` and avoid posting exploit details publicly.

## Before Asking For Help

Please include:

- Ghost-Env version or commit
- Operating system
- Command you ran
- Expected result
- Actual result
- Sanitized sample `.env` content using fake values only

Do not share real `.env`, `.env.ghost`, keychain exports, API keys, database URLs, or tokens.
