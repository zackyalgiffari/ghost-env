# Roadmap

This roadmap tracks public project direction. `plan.md` is the original planning artifact; this file is the maintained roadmap.

## Current

- Rust CLI scaffold
- OS keychain-backed master key
- Encrypted `.env.ghost` vault
- `.env` mask generation
- `.ghostignore` mask overrides
- `ghost-env run` process injection
- CI and release scaffolding
- Open-source project documentation

## Next

- Real-world keychain testing on macOS, Linux, and Windows
- Better `.env` parser compatibility for multiline and escaped values
- More mask pattern coverage for common providers
- Release dry run with cargo-dist
- Manual Winget publishing workflow

## Later

- Vault format migration policy
- Shell completions
- Man page generation
- Configurable vault and mask paths
- Audit-focused security review
- Signed release artifacts
